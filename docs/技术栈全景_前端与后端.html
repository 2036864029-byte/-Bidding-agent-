1. 技术栈总览

系统采用前后端完全分离架构：前端为独立 npm 包 ztb-frontend，后端为 Python 服务，二者仅通过 HTTP REST + SSE 通信。开发期由 Vite 代理 /api → 127.0.0.1:8000（rewrite 去掉 /api 前缀），生产环境由反向代理同域转发。

统计概览

维度 前端 后端
主语言 TypeScript 5.9 Python 3.11
直接依赖 19 项（dependencies） 18 项（requirements.txt 顶层）
开发依赖 14 项（devDependencies） dev 组由 uv 管理（含 ragas）
核心框架 React 19 + Vite 6 FastAPI + LangGraph
构建 / 包管理 Vite 6.4 / npm uv（uv sync --frozen --no-dev）
测试框架 Vitest 5 + Testing Library pytest + RAGAS
运行时形态 浏览器静态资源 Docker 容器 + GPU 模型服务

6. 依赖治理与版本约束

约束 原因 影响面

7. 选型决策摘要

编号 决策 理由
AD-F1 Vite + React 19 + TS 冷启动与 HMR 快；TS 全量约束降低适配层出错概率
AD-F2 Tailwind v4（CSS-first @theme） 设计 token 直接写在 CSS，去掉 JS 配置层；与 Shadcn 生态契合
AD-F3 Shadcn + Radix（源码入仓） 组件可任意改，无第三方 UI 库版本锁定风险；Radix 保证无障碍
AD-F4 自研适配层 + Mock 同形 后端字段变更只改适配器；mock 与真实同形状，使演示期测试仍有意义
AD-F5 fetch-event-source 而非原生 SSE 原生 EventSource 不支持 POST 与自定义请求头
AD-F6 路由级懒加载隔离 Recharts 图表库约 438 KB，与对话/落地页首屏解耦
AD-B1 LangGraph 状态机 子图 / 条件边 / Checkpointer 原生支持多分支 Agent
AD-B2 langchain-openai 统一接入 所有模型走 OpenAI 协议，换供应商只改 .env
AD-B3 能力注册表数据驱动 新增分支不改 router / graph，符合开闭原则
AD-B4 模型服务外置 + GPU 透传 主镜像去 torch，体积与构建时间大幅下降
AD-B5 评测判定模型与生成模型不同源 规避自评偏差
AD-B6 Milvus 服务端 BM25 稀疏计算下沉，应用侧零开销
