# 书1 法规合集形态修复执行计划（2026-09-07）

> 状态：设计稿（未动代码）。背景诊断见 2026-09-07 会话（`scripts/diag_p15_steps.py` 只读复现 + 全库证据链）。
> 目标读者：用户决策用；落地时按此计划分步执行、逐步验收。

## 0. 背景与目标

书1《中华人民共和国招标投标法律法规全书》是唯一一本"法规合集"（约 50 部法规合订），
用户期望结构 = **法规名 H1 → 章节 H2 → 条文 H4**。当前 v3 产物四类症状：

1. **法规名当正文**（全书 159 个法规名形态行，144 个即 90.6% 是正文）；
2. **每部法律开头丢"第一章"**（"第一章 总 则"标题全书零存活，属数据丢失）；
3. **层级错乱**（页首 mini 目录的章名行被判成 H2 幻影标题，与真实章标题并存）；
4. **版面不统一**（同为法规名，有的 H1 有的正文）。

书2/书3 无此症状（书2 解读体无 mini 目录、书3 手册体无跨法高频同名章标题）。

**核心认知（决定方案走向）**：这四个根因**都不在双栏/栏序代码里**（`reflow_two_columns_v2`
正常），而在**所有书共享的** 标题判定 / 行频去重 / 前置剥离 逻辑，只是被书1 的
"每法首页多层字号排版 + 75 页同款章标题 + 页首 mini 目录"三特征叠加触发。
因此修复应走**共享逻辑内容模式修复 + 三书门禁兜底**，而非拆双栏独立链路
（详见 §8 备选方案对比）。

## 2. 修复设计（P1~P5）

### P1｜去重保护正则修复（RC2，纯 bug 修复，风险最低）

- **文件**：`public_kb/ingestion/normalizers/pdf/pdf_markdown_assembler.py`
- **改动**：`dedup_repeated_lines` 的行频豁免，从"只豁免裸 `第X编/章/节/条` 开头"
  扩为"豁免 markdown 形式与裸形式的法律标题行"：
  `^(?:#{1,6}\s+)?第[一二三四五六七八九十百千\d]+[编章节条款项]`。
  即 `## 第一章 总 则` 与 `第一章 总 则` 都不进重复计数。
- **边界**：非法律标题的重复行（侧边栏页签 `1.一般规定`、页脚等）照常去重。
- **残余风险（记档）**：未来若有"章名页眉"（每页顶部重复真实章名）的书，
  此修复会使其存活为重复 H2。缓解：①解析层 `remove_header_lines` 有区位证据
  （页顶/页底带）先兜；②"可见的重复 H2"劣于"静默数据丢失"，且 Phase B 分块
  时可见可处理。本计划不额外加"布局去重"。
- **测试**：`## 第一章 总 则` 重复 ≥5 次存活 / 裸 `第一章 总 则` 存活 /
  非法律重复行（`1.一般规定`）仍删。

### P2｜法规名标题规则（RC1，增量加规则）

- **文件**：`public_kb/ingestion/normalizers/pdf/pdf_paragraph.py`
- **位置**：`heading_level_layout` 的模式兜底之后、`return None` 之前；
  调用方 `assemble_paragraphs` 把"上下间隙隔离"标志传入（函数当前无邻居上下文，
  需加一个参数，默认 None = 守卫禁用，与 `col_right` 同款约定）。
- **规则（法规名 → H1）**，全部条件满足才命中：
  - 文本长度 4 ≤ len ≤ 40；
  - **形态**：`^中华人民共和国` 或 尾部命中
    `(法|条例|办法|规定|细则|暂行规定|暂行办法|实施办法|实施意见|通知|函|纲要|规划)$`；
  - **排除**：以句末标点（`。！？…；，、：`）结尾 → 正文；行首 `第X编/章/节/条`
    或列表号 → 走既有模式路径（不在此规则）；`full_width`（排满本栏版心）→ 正文；
  - **版面证据（至少一项）**：上下间隙隔离（≥1.5×line_gap）/ `centered` /
    `size ≥ body_size×1.05`（粗粒度，size_ok 门禁失效时仍可用）。
  - 级别：**1（H1）**。
- **沿革行降级（用户 2026-09-07 定 D1=B）**：识别含年份的编号行 + 通过/公布/施行/
  修正 语义（如 `1. 1997年12月29日…通过`、`2. 根据…修正`），一律降为 H1 下的
  普通正文行——不判 `######`（现状：中段法沿革行的数字项被列表模式拍成 H6 垃圾标题）。
  沿革行识别规则独立于"法规名"规则，避免数字列表误伤。
- **为什么不动 `size_ok` 门禁**：门禁是"OCR 字号噪声"泛化护栏，动了影响所有书。
  本规则用**内容形态 + 间隙隔离**替代字号证据，避免在门禁失效页上依赖不可靠的字号。
- **已知局限（记档 + 决策点）**：多层字号页上"仅靠字号微大"的其他标题（如节标题）
  仍可能漏判。若书1 实测还有此残留，再评估 `size_ok` 的度量方式（如按紧簇估 body
  而非全列 spread）——本计划**不预做**。
- **测试**：法规名（中华人民共和国…法 / …办法 / …暂行规定，间隙隔离）→ H1；
  正文句尾行（…执行。）→ 不判；引用句（…的规定，认定无效。）→ 不判；
  `full_width` 行 → 不判；沿革行（含 年份+通过/公布/施行/修正 的编号行）→ 正文非 H6。
  书2/书3 抽样干跑零新增 H1。

### P3｜mini 目录剥离（RC3，用户 2026-09-07 决策：直接剥离，不保留 TOC 标记）

- **文件**：`public_kb/ingestion/transforms/structure.py`（`mark_inline_toc` 改为剥离
  语义或新增 strip 函数由 handoff 调用）。
- **现状**：连续 ≥2 个 ≤20 字章标题行（行间无正文）被包 `<!-- inline-toc -->`；
  且书1 页 15 的 run = 6 个 mini 章名录 + **真实"第一章 总 则"**（相邻无正文），
  会把真实章标题也误包进 TOC。
- **规则（剥离）**：run 判定不变；**当 run 末行之后紧跟正文（非标题、非空）时，
  末行是真实标题——保留为标题，仅剥离 run 内其余行**；若 run 后无正文（纯目录页），
  整段剥离。沿用 `_is_legal_heading_cascade` 守卫（编→章→节递降级联不误标）。
- **一致性收益**：首法 mini 目录由前置剥离删、中段法由本规则剥离 → 全法一致。
- **注意**：剥离后不再需要 inline-toc 标记（Phase B 无需消费）；原 `mark_inline_toc`
  的既有测试相应改为"剥离"断言。
- **风险**：连续 ≥2 个真实空章标题（无正文）会被误剥——由"末行跟正文则保留"规则
  兜底；实测无此形态。
- **测试**：6 行章名录 + 真实第一章 + 正文 → 前 6 行被剥离、末行保留为 `##`；
  编→章→节级联不动；纯目录页整段剥离；幂等。

## 8. 备选方案对比（用户 2026-09-07 提出，结论：暂缓）

**A. 双栏独立链路 —— 不采纳**：根因不在双栏代码，拆了修不好当前问题；共享逻辑复制
两份 = 双份维护 + 分叉（09-06 已拍板"不拆两条链路"）；且 RC2 去重 bug 对**单栏**合集
书同样致命，独立双栏链路救不了未来单栏数据。

**B. PaddleOCR 轻量版面分析（出块坐标+类型 → 回传本地解析）—— 技术可行，暂缓**：
①标准版面模型分类表无"目录"类，mini 目录仍靠文本启发式（RC3 解决不了）；
②本体裁精度未验证，09-05 PP-StructureV3 试点已在同类扫描件翻车（表格→text 0.986）；
③需渲染页面 + 坐标系映射 + 类型→层级映射 + 与文本证据冲突的回退，新失败面大；
④不解决 RC2（纯文本去重 bug）。
**启用条件**：未来真实扫描双栏数据量大、文本层弱时，作为"版面信号锚点"接进现有
段落逻辑（给 `heading_level_layout` 喂"此行是标题"的外部证据），仍走单链架构。
