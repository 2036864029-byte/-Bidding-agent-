## 1. 总体策略

**版面证据前移，文本猜测退役。**

- 段落/标题/栏序判定所需的全部证据（缩进、排满、垂直间隙、字号、加粗、x0/x1/y0）在 fast_text 的 `TextLine` 里已经齐备，现状是"算了不用"。本计划把它们真正用起来，判定全部落在解析层。
- clean 层（A3/A4/R1~R5）从"结构修复主力"收缩为"兜底校验"，能退役的退役。
- 不改 MinerU 服务端、不引入 LLM 重构、不依赖新的外部解析。

**产出形态变化（用户决策已定）：**
- raw.md：仍为解析层产物（内容升级为段落化 + 版面锚定标题）；
- clean/assembled.md：一段一行 + 版面锚定标题层级 + 表格 md 原子块；
- chunks：随 clean 全量重建（chunk_uid 必然漂移，见 §7 决策点）。

## 2. 分阶段计划

依赖关系：P1 是核心底座；P2/P3 依赖 P1 的段落结构；P4 依赖 P1~P3 稳定后收缩 clean 层；P5 独立可并行；P6 贯穿。

### P1 fast_text 段落化重构（核心，预计 3~4 天）

改动文件：`public_kb/ingestion/normalizers/pdf/pdf_fast_text.py`（主体）、`pdf_two_column_reflow.py`（P1 落地时顺带通栏序修复，见 P2）、新增 `pdf_paragraph.py`（段落装配，独立可测）。

- **P1-1 版面基准线**：每页（每栏）计算 `left_edge`（正文行 x0 众数）、`right_edge`（x1 最大值）、行距基准（相邻 y0 差中位数）。
- **P1-2 段落三判据**（任一命中 = 新段起点）：
  1. 首行缩进：`x0 > left_edge + 1.5×字宽`；
  2. 上段收尾：前一行 `x1 < right_edge − 2×字宽`（段尾排不满）；
  3. 垂直间隙：`y0 − 前行y1` > 行距基准 × 1.6。
  段内视觉行合并为**一行**（复用 `relayout._join_cjk` 的 CJK 连接/ASCII 空格逻辑，迁到公共位置）。
- **P1-3 标题判定重写**（`_heading_level`）：
  - 版面优先：`size ≥ body×1.15`（或 `bold` + 短行 + 无句末符）→ 标题；`centered && size ≥ body×1.2` → 章级；
  - 文本模式降级为辅助：模式命中但 `size ≈ body` 且非 bold → **正文**（消灭 H4 洪水的主刀）；
  - `bold` 字段首次实际使用。
- **P1-4 标题跨行合并**：标题行（版面判定）后紧跟的非缩进短行且非新段起点 → 吸收（版面证据充分，无需 R4 的 26 字/2 行窄护栏）。
- **P1-5 特例白名单**（保持逐行/逐块，不合并）：表格行（`|`）、表单下划线行、图表题注行、独立列表项（顶格 + 后续缩进结构）。串栏防御在 P2-2 兜底。

验收：
- 单测（`test/test_paragraph_assembly.py` 新增）：合成 `TextLine` 页构造缩进/排满/间隙/标题截断各 case；段落边界准确率断言。
- 书2 试点（单栏 756 页，无 MinerU 干扰）：抽 20 页人工比对 PDF 原版，段落还原 ≥95%；`####` 洪水显著下降（H4 数量从 532 降到与真实标题量级一致）。

### P2 双栏路径修复（1~2 天，可与 P1 合并实施）

改动文件：`pdf_two_column_reflow.py`、`pdf_legal_page_classifier.py`、`pdf_page_profile.py`。

- **P2-1 通栏行按 y 序插回**：`reflow_two_columns` 不再 `full+left+right`，通栏行按 y0 归位到左/右栏流中（跨栏标题落到其真实位置）。
- **P2-2 串栏防御（Q1 核治）**：`text` 路径进入 `sort_single_column` 前检查"行宽中位数 ≪ 页宽（如 <0.55）且 x0 双峰"→ 转 `two_col` 处理或标 uncertain 送 reflow；不再无脑全页 y 序。
- **P2-3 分类器特征增强**：`_detect_two_col` 在 x0 间隙之外增加 x1（右边缘）双峰佐证——表单页左右栏 x0 相近但右边缘可分。

验收：法规全书 15 页串栏页重处理后行序通读；单测覆盖"x0 无间隙、x1 双峰"case。

### P3 装配层跨页续段与 mini 目录（1~2 天）

改动文件：`pdf_markdown_assembler.py`（`assemble_pages`）、`pdf_router.py`。

- **P3-1 跨页续段合并**：在 `assemble_pages`（页标记尚在、页结构可知）做：前页末段无句末收尾/末行排满且后页首行非缩进非标题 → 合并（跨栏跨页断句根治，R5 永远做不到的那类）。
- **P3-2 mini 目录识别**：法条汇编内每部法律自带的目录区（连续短行 + `第X章/节` 条目 + 页码尾或被截断特征）→ 打 `<!-- toc: 目录 -->` 标记或剔除，不再以 H2 进入标题流（Q5）。

验收：法规全书 clean 中相邻 `## 第X章` 错乱消失；跨页断段抽查 20 处全部粘合。

### P4 clean 层收缩（1~2 天，依赖 P1~P3 落地）

改动文件：`public_kb/ingestion/transforms/relayout.py`、`structure.py`、`handoff.py`、`core/config/settings.py`。

- **P4-1 R5 退役**：输入已一段一行，`_wrap_sentences(width)` 与 `_reflow` 单元逻辑整体停用（`enable_pdf_relayout` 语义收缩或新增 `pdf_layout_v2` 开关，灰度期双轨）。
- **P4-2 R4 退役**：标题续行合并已由 P1-4 版面完成。
- **P4-3 R1/R2 保留**（目录残标题/引用降级是纯文本问题，仍需兜底），跑 A5 保真回归确认残留清零或可解释。
- **P4-4 A3-1/A4 改版面锚定**：标题级以解析层输出的 `#` 为准；`_CONTENT_LEVELS` 只校验不重写（模式行层级与解析层冲突时记 report 而非改写）。消除"固化误判"（Q6）。
- **P4-5 幂等契约**：一段一行天然幂等，`clean(clean(x)) == clean(x)` 回归保留。

### P5 表格还原（用户决策 2026-09-06：优先级后移）

- **有框表启用 Tier B**（`table_extractor` 骨架已预留）在主干稳定后顺手接入；**无框表（A/B/C）后延**——能处理最好，处理不好不阻塞，表格页在接入前维持现状。不设排期承诺。

### P6 全量重处理与验收（1 天 + 跑批）

- **P6-1 重跑链路**：fast_text 页本地重解析；MinerU range 走既有缓存零调用。**产物输出到新目录 `DATA/raw_data/handoff_v3/`**（raw 重写为新版解析产物；`handoff_v2` 与 backup_20260905_185337 原样不动，用户决策 2026-09-06）。
- **P6-2 chunks 不随本次重建**（用户决策 2026-09-06）：数据处理合格后 Phase B 会重设计分块方式，届时一并重建；本次验收只对 clean/raw 资产。
- **P6-3 验收装置**（与 §6 测试套件一体）：
  - 段落还原率：抽样页人工比对（目标 ≥90%，书2 试点 ≥95%）；
  - 行长分布：≤30 字行占比 ≤5%（现状 21%~37%）；
  - 标题直方图：H4 与真实标题量级一致，层级跳变 ≈0；
  - 串栏检测：双栏书重处理页行序通读率；

  - 黄金页快照随新解析版本重建（`scripts/build_golden_pages.py --update-baseline`）。
- **P6-4 存量测试适配**：`test_relayout.py`、`test_structure_repair.py` 等涉及 R4/R5/A3-1 行为的用例按新契约改写；全量 `python -m pytest test/` 回归（基线 692 passed）。

### 6.2 总体测试（资产级验收门禁，显式启用）

`test/test_layout_metrics_gate.py`（`RUN_LAYOUT_GATE=1` 启用，对 `handoff_v3` 产物跑）：
- 行长分布：clean 正文 ≤30 字行占比 ≤5%；
- 标题质量：标题未收尾（无句末/无【】/无收尾符）计数 ≈0；标题占正文行比例 ≤15%（现状 H4 洪水 ~40%）；
- 幂等：`clean(clean(x)) == clean(x)`；
- 字符保真：按 A5 Counter 口径抽页比对。

### 6.3 泛化护栏（反过拟合硬约束，写码与评审共同遵守）

1. **阈值相对化**：所有判定阈值相对于页面实测基准（left_edge 众数、行距中位数、body_size 中位数），禁止绝对 pt/字数硬编码；每个阈值给一句"为何该值通用"的依据。
2. **禁止书/页硬编码**：不得出现书名、页码、具体标题文本常量；一切模式驱动。
3. **两层验收**：合成单测（规则正确）+ 三书真实抽页（分布正确）；后续新书到达时先跑 6.2 门禁再入链。
4. **失败降级**：版面判定置信不足（如基准线算不出）→ 回退旧行为并记 manifest warning，不静默产出坏数据。
