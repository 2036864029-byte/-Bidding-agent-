## 0. 结论先行

| 项 | 判断 |
| --- | --- |
| 参考站真正的调性是什么 | **纯白纸 + 近黑字 + 一个荧光信号色（酸性青柠）+ 一个功能蓝 + 胶囊形控件**，动效极轻 |
| 我们和它最大的差距在哪 | **不在配色，在"重量"**：中文标题没有 display 字体、字重只有 600、墨色只有 24% 亮度 → 整体发灰发轻 |
| 建议怎么改 | **取骨架、不取全身**：换成「白纸 + 墨黑 + 一个青柠信号」，蓝色降为功能色；荧光色只做"底/标记"，不做"字/线" |
| 工作量 | 3 期，约 3 个工作日（token 0.5d / 组件 1d / 页面 1.5d） |
| 最大风险 | 荧光青柠在严肃的政企采购场景里用过头，会掉可信度 → 用"信号色 ≤5% 视口"硬约束住 |

## 1. 参考站 DNA 实测

### 1.1 色彩（CSS 内出现次数即使用强度）

| 角色 | 实测值 | 次数 | 判读 |
| --- | --- | --- | --- |
| 纸面 | `#FFFFFF` | 85 | 纯白，不吃灰 |
| 主墨 | `#080808` / `#000` / `#222` | 34 / 17 / 10 | 近黑，标题与正文同色，靠字重区分层级 |
| **信号色** | `#E4FF31`（另有 `#EEFF6D` `#EEFF6F` `#E1FF00` 渐变档） | 8 | **酸性青柠**，全站唯一"抓眼"的颜色 |
| 功能蓝 | `#005EFF`（另有 `#0E59FF` `#3578FF`） | 8 | 按钮/链接/选中 |
| 辉光青 | `#00B7FF` `#94E1FF` `#79F6FF` `#94F8FF` | 3 / 6 / 2 / 2 | **只用于渐变光斑**，不承载信息 |
| 次级灰 | `#4E5366` | 6 | 说明文字 |
| 装饰粉 | `#F9CBFF` `#FDEEFF` | 2 / 2 | 极少量渐变过渡 |

渐变用法（`rgba(228,255,49,0)`、`rgba(148,225,255,0)`、`rgba(0,94,255,0)`）说明：**所有光斑都是"色 → 全透明"的径向渐变**，没有硬边色块。

### 1.2 字体（这是调性的真正来源）

```
font-family: FZLanTingHeiS-EB-GB, PingFang SC, Microsoft YaHei, sans-serif   ×7   ← 标题（极粗）
font-family: FZLanTingHeiS-DB1-GB / DB-GB / B-GB / M-GB / R-GB                ×13/4/8/3/1
font-family: Alimama ShuHeiTi（阿里妈妈数黑体）                                ×3   ← 数字/大标题
font-family: DingTalk JinBuTi（钉钉进步体）                                    ×3   ← 强调数字
font-family: Inter                                                            ×4   ← 拉丁/西文
```

要点：**这是一个"中文黑体多字重"体系，不是"一个西文字体 + 系统中文回退"**。标题的压迫感来自中文字体本身的极粗字重（EB / Heavy），不是字号。

### 1.3 形状与间距

| 项 | 实测 |
| --- | --- |
| 大容器圆角 | `min(69.375vw, 999px)`、`266.4vw` → 巨型胶囊/药丸 |
| 按钮圆角 | `999px` 胶囊 |
| 卡片圆角 | `8px` / `12px` / `16px` / `24px` / `min(1.944444vw,28px)` |
| 间距写法 | 一律 `min(N vw, Npx)` —— 随视口线性缩放，桌面端封顶 |

### 1.4 版式结构

```
吸顶导航（logo + 5 锚点 + 主/次 CTA）
hero（品牌 logo + 副标 + H1 + 一句副文 + 2 个 CTA + 整幅产品截图 + 水印底纹）
真实反馈（3 条证言，人像 + 姓名职务 + 短评）
四大亮点（01–04 编号卡，每卡一个动词 + 一个汉字总结）
功能展示（行业 tab 切换 + 修改前/后左右对比）
产品能力（01–06 编号清单）
产品对比（表格：维度 × 传统 vs AI）
预约 CTA（单一动作）
footer（隐私/协议 + 回到顶部）
```

### 1.5 动效

CSS 全包里只有 **1 个** `@keyframes`（`reservation-success-enter`），页面技术栈是 Vue 3 + Pinia + axios，**未引 framer-motion / gsap / lottie / lenis**。

结论：**它的"高级感"几乎不来自动画**，来自字重、留白、纯白纸和克制的单点荧光色。这条对我们尤其重要——我们已经有 framer-motion，不缺动效，缺的是静。

### 1.6 不能照搬的部分

| 参考站的做法 | 为什么不能搬 |
| --- | --- |
| 满屏荧光青柠/辉青光斑 | 我们只有 4 个功能界面，不是营销长页；光斑铺满会稀释信息层级 |
| 证言区 / 产品对比表格 / 内测预约 | 我们没有这些内容，编造客户证言会直接违反"不编造"纪律 |
| 巨型 hero 产品截图 | 我们的产品截图就是对话窗口本身，再套一层截图是重复 |
| 方正兰亭黑 | **商用需授权**。若真要落地须换免费可商用字体（见 §5） |

## 3. 调性定位：三档，推荐 A

参考站是**营销长页**，我们是**工作台**。同样的调性搬进来，剂量必须减。三档供你选：

### A 档 · 「黑白 + 单信号」（推荐）

- 纸面纯白、墨色 `#080808`（骨架照搬参考站）
- **青柠只做信号**：主按钮底、选中标记、图标底座、强调 chip、图表高亮
- 蓝 `#005EFF` 降为**功能色**：链接、选中态、图表序列
- 胶囊按钮 + 24–28px 卡片 + 发丝线（形状语言照搬）
- 光斑最多 2 个，且只允许出现在落地页 hero 与空状态插图
- 观感：**专业、干净、有一点锋芒**

### B 档 · 「原味照搬」

青柠 + 电蓝双色渐变、胶囊按钮、多处光斑、超大标题。适合做官网/发布会，不适合天天用的工作台——用户连续看 8 小时后，荧光色会变成噪声。

### C 档 · 「只改版式，颜色不动」

保留钴蓝，只改字重、留白、圆角、密度。最保守，风险最低，但和"参考站调性"基本无关。

**建议：A 档。** 下面所有规格按 A 档写；如果你选 B 或 C，§4 的 token 表按对应列替换即可，组件与页面章节不变。

## 5. 字体方案

### 5.1 问题本质

```css
/* 现状 */
--font-display: "Space Grotesk", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

Space Grotesk 无中文字形 → 所有中文标题实际落在 **PingFang SC 常规**，600 字重的声明只对拉丁字符生效。这就是"标题看起来没有份量"的根本原因。

### 5.2 建议（免费可商用，避开方正兰亭黑的授权问题）

| 用途 | 建议字体 | 授权 | 说明 |
| --- | --- | --- | --- |
| 中文标题 | **HarmonyOS Sans SC Bold / Heavy** 或 **阿里巴巴普惠体 3.0 85** | 免费商用 | 与参考站"方正兰亭黑 EB"最接近的观感 |
| 中文正文 | 系统 PingFang SC / 微软雅黑 | 系统自带 | **不引入**，避免体积与首屏阻塞 |
| 拉丁标题 | 保留 Space Grotesk | @fontsource 已有 | 与中文粗体搭配 |
| 数字/等宽 | 保留 JetBrains Mono | 已有 | 表格数字继续 tabular |

### 5.3 落地约束

- **只引 1 个字重**（标题 700 或 800），不要引 M/R/B/DB 全套。
- 中文字体全量 woff2 约 2–4 MB/字重 → 必须**子集化**（常用 3500 字）压到 300–500 KB，或走 `unicode-range` 分片。
- 一律 `font-display: swap`，避免字体阻塞首屏。

- **删掉 `.gradient-edge`**（`index.css:204` 的旋转渐变描边 + 三层外发光）。它现在是页面最亮的元素，与"信号色 ≤5%"冲突。

- 聚焦态：`box-shadow: 0 0 0 3px` 青柠 18% 淡环（**不是**蓝环、**不是**发光）
- 发送按钮：青柠底墨字胶囊；生成中变 `secondary` 停止键（现有逻辑不动）
- `+` 上传键：钴蓝 → 墨黑，hover 旋转 90° 保留

### 6.5 引用卡（`components/chat/Citations.tsx`）

- 引用标记 `【来源N】` 用**青柠底墨字**小标签（这是"可核验"的产品主张，值得用信号色）
- 但**正文里的引用密度高**，所以标签只着色底、不加粗、不换字号

### 6.6 数据表（`components/chat/PriceRecordsTable.tsx` + `.md-body table`）

- 表头：`paper-2` 底 + `muted` 字 + `500` 字重
- 行 hover：`signal-soft` 的 40% 淡底（**不要**用整行青柠）
- 数字：`tabular-nums` 保留
- 金额列：右上角 `tnum` 对齐

### 6.7 图表（`ChartCard` 及三个 kanban 图）

**这一条必须单独立规矩**：图表序列色**不能**跟着换成青柠。

- 主序列：`#0076ED` → **`#005EFF`**（对比度 5.19:1，白底可辨）
- 青柠**只做**：选中柱的高亮、预测区间标注、异常点标记
- 现有分类色板 `--cat-1/2/3` 已过 CVD 校验，**原样保留**

原因：`#E4FF31` 对白 **1.13:1**，作为数据线在白底上等于不可见。颜色是算出来的，不是挑出来的。

## 11. 风险与取舍

| 风险 | 应对 |
| --- | --- |

### 12.7 缺陷修复：「开始」在非首页是死按钮

**用户反馈**：点「功能介绍」进入 `/intro` 后再点「开始」，没有任何反应，像卡住。

**根因**（与 12.6 结尾提到的"同路由"问题无关，是另一个独立 bug）：

- `SiteHeader` 被 4 个页面共用：`/chat`、`/intro`、`/faq`、`/links`
- 但 `#modules` 只存在于 `/chat`（`LandingLayout` 内）
- 旧实现只有一行：`document.getElementById('modules')?.scrollIntoView(...)` —— 在非首页取到 `null`，**可选链把空指针静默吞掉**，于是点击既没有滚动也没有跳转

这类 bug 的危险性在于：没有报错、没有日志、类型检查也过（`?.` 正是为了"安全"），只能靠点击才发现。

**修复**：按路由分流

```ts
const goModules = () => {
  if (pathname === '/chat') { scrollIntoView(...); return; }  // 首页内直接滚
  navigate('/chat#modules');                                  // 其它页面先回首页
};
```

`LandingLayout` 增加对 `location.hash === '#modules'` 的监听，用 `requestAnimationFrame` 等首屏渲染完再滚动落位。

**验证**：新增 `src/test/site-header.test.tsx`（3 例：首页滚动 / `/intro` 跨页 / `/faq`·`/links` 跨页）。
浏览器实测：`/intro` 点击「开始」→ `path=/chat` `hash=#modules` `scrollY=855` `#modules` 顶边 `=60px`（导航高度），与首页内点击的结果完全一致。

### 12.19 主界面底色：明蓝 → 深蓝渐变（走向照参考图）
