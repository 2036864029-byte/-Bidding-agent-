# 主页面优化执行方案（2026-09-14）

> **输入**：《docs/plan1/主页面优化.md》（用户指令）+ 09-14 会话三轮决策（导航占位/渐变收敛/浮窗形态/版心对齐）+ 既有设计体系（Hallmark Cobalt-tuned，见 `frontend/src/styles/index.css`）。
> **目标**：解决 Phase 1 落地页「层次乱、品牌重复、对话模块过重」问题，重构为**吸顶导航 / 介绍带 / 模块入口 / 对话**四层清晰形态，视觉上更聚焦、更精致。
> **关联**：《前端架构与UI版面设计方案_20260914.md》§4.1 落地页设计（本方案为其落地页部分的修订执行）。

---

## 0. 结论速览

- **形态**：吸顶导航（4 个占位页）→ 浅蓝介绍带 → 三张增强模块卡 → 对齐 72rem 版心的渐变输入条 → 发送后**聚焦浮窗**（× 收起、可恢复会话）。
- **渐变纪律（采纳评审建议，发光唯一化）**：发光签名**只留对话框一处**（输入条 + 浮窗，常亮慢速 drift 14s）；卡片 hover 只做「边框变钴蓝 + 轻发光」；介绍带用**纯色浅蓝块**，不做渐变。
- **会话纪律（多轮不丢）**：浮窗 × = **收起**（非销毁），收起为「对话中」胶囊，点击恢复同一会话；`messages`/`session` 语义已入 Zustand，Phase 4 接真后端时只换回复生成逻辑。

## 2. 页面结构（落地页 = /chat）

```
┌──────────────────────────────────────────────────┐
│ 吸顶导航：招小智 · 功能介绍 常见问题 移动端连接 友情链接 │
├──────────────────────────────────────────────────┤
│ 介绍带：从询价、供应商到商机，一站式智能分析（浅蓝块）     │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐           │
│ │ 智能询价  │ │ 供应商全景│ │ 商机看板  │  ← 增强卡片 │
│ │ 能力标签+ │ │ 能力标签+ │ │ 能力标签+ │    (hover 发光)│
│ │ sparkline│ │ sparkline│ │ sparkline│           │
│ └──────────┘ └──────────┘ └──────────┘           │
│            （py-12/14 间隔）                        │
│ ┌────────────────────────────────────────────┐   │
│ │ [＋上传] [输入…] [发送]  ← 渐变描边签名，72rem 对齐  │   │
│ └────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────┘
       │ 发送
       ▼
┌──────────────────────────────────────────────────┐
│     背景虚化 + 压暗遮罩（点击=收起）                  │
│   ┌────────────────────────────────────────────┐ │
│   │ 对话 · N 条消息                          [×] │ │
│   │  [用户气泡]                                  │ │
│   │  [Agent 占位回复]                            │ │
│   │  [＋上传] [输入…] [发送]                      │ │
│   └────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
       │ ×
       ▼  「对话中 · N 条消息」胶囊（点击恢复）
```

**状态模型**（`store/chat-window.ts`，Zustand）：

- `status: 'idle' | 'open' | 'minimized'`
- `messages: { id, role: 'user'|'agent', content }[]`
- `input: string`（dock 与 panel 共用一份草稿，收起不丢）
- actions：`setInput` / `submit`（追加用户消息 + 占位回复，置 open）/ `open` / `minimize`

交互规则：
- dock 发送（idle/minimized）→ open，消息入列表，输入移入浮窗；
- 浮窗 × / ESC / 点击遮罩 → minimized；dock 输入条回归 + 显示「对话中」胶囊；
- 胶囊点击 → open，同一会话恢复。

## 4. 样式要点（沿用 Cobalt-tuned 纪律）

- `.gradient-edge`：`padding:1.5px` + 钴蓝低饱和线性渐变 + `background-size:220%` + **drift 14s**（`prefers-reduced-motion` 下退化为静态）；内层 `bg-paper` 同圆角。
- `.card-glow`：hover `translateY(-4px)` + `border-color → accent` + 钴蓝轻发光阴影（`0 0 0 1px accent, 0 18px 48px accent/0.35`），无旋转渐变。
- 介绍带：`bg-accent-soft` 纯色块 + 发丝线，无渐变。
- 动效三档/三曲线不变；所有空间动效尊重 `prefers-reduced-motion`（全局已折叠为 ≤150ms 透明度）。
- 浮窗 `max-w-[72rem]`、`max-h 70vh` 内滚、`z-[70]`（高于 header z-50）、`aria-modal` + ESC 收起。

### v4 修订（2026-09-14 傍晚 · 用户三/四次反馈 + bug 修复）

| 反馈/问题 | 修订 |
|---|---|
