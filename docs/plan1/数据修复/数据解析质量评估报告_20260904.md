> 评估日期：2026-09-04

> 评估目的：量化当前解析/清洗/分块产物的问题占比，作为后续优化调整的前后对比基线；**未改动任何数据处理代码**。

## 1. 两条数据路径与技术栈

### 1.1 Path A —— handoff（3 本电子书）

```
源 PDF
  → PdfRouter 三档路由（pdf_tiered_routing_enabled=true）
      Tier A  fast_text：PyMuPDF get_text("dict") 行级抽取（无表格抽取）
      Tier C  MinerU 云端解析（magic-pdf 1.3.12）
  → T4 装配：页标记 <!-- page: N --> + 标题级别规范化 + 页眉/页脚去重(dedup≥5次)
  → TextCleaner：重复行去重 / 删页码行 / 删 <10 字符短行 / 压缩空行
  → adapt_pdf_markdown：表格原子块(按 | 行)、目录点线过滤、双栏乱序打标
  → SemanticChunker：按 Markdown 标题切块（## 章 / 第X条→####），2000字按句再切
  → documents.jsonl（分块入库）
```

关键组件：`public_kb/ingestion/normalizers/pdf/pdf_fast_text.py`、`pdf_two_column_reflow.py`、`pdf_markdown_assembler.py`、`transforms/cleaner.py`、`transforms/chunker.py`、`normalizers/pdf/pdf_structure.py`。

### 1.2 Path B —— cleaned_v1（349 份法规，外部链路 `rag_cleaned_policy`）

外部导入链路清洗产物（非本仓库代码生成）：`markdown/*.md`（每文一档）+ `manifest.csv` + `documents.jsonl`（含 `content_md` 全文）。本仓库只消费其 markdown 做入库分块。

## 2. 用户列出的 6 类问题统计（Path A 三本书）

### 2.1 问题①：双栏文件结构还原不合理

- 全书 **348/407 页（85.5%）** 被路由为双栏，经 `reflow_two_columns` 按“左栏→右栏”拼接还原。
- 阅读顺序本身基本正确（抽样第 12 条，左栏→右栏拼接后语句连贯），**但行级被切成碎片**：双栏行尾短碎片（“任 / 何单位…”“招标代 / 理机构…”）在清洗后被 `TextCleaner` 删短行（<10字）再次丢失，如“理机构。”整体消失（见 2.6）。
- 双栏页**标题行被从中间截断**：`#### 第十条 招标投标法第十二条第二款规定的招标人具`（续“有编制招标文件…”）、`#### 第十二条 招标代理机构应当拥有一定数量的具备编`（续“制招标文件…”）等。
- 当前启发式打标 `pdf_layout_suspect` 命中 43 块（全书）/ 7 块（白如银）/ 0 块（1200问）——只覆盖“块内条文号≥12”的极端情况，实际碎片化远比打标多。
- 白如银/1200问 双栏页极少（4/2 页），双栏问题占比低。

### 2.2 问题②：章节信息缺失，条款被当成标题

- **全书标题层级**：`#`309 / `##`340 / `###`203 / `####`3957（其中 `第X条` 级标题 2804 个，含 `【正文】` 的 302 个）。
  - 目录页 `## 目 录` 标题污染：其后的法条内容 chapter 全部带“目录 > ”前缀（见 3.3.4），章节树被目录页绑架。
  - 302 个“第X条【…】+ 正文首句”标题：如 `#### 第十二条【自行办理招标和招标代理】招标人有权`，正文首句“招标人有权”被并入标题，**正文中丢失**。
- **白如银**：`#`122 / `##`37 / `###`88 / `####`577 / `#####`272。MinerU 页统一输出 `#`（章节/小节/正文标题均一级），与 fast_text 页的 `## 章`/`### 节`/`#### 条` 混排 → **同书内标题级别倒挂**（`# 招标投标的起源与发展` 高于 `## 第一章`）。
- **1200问**：`#`454（章节、问题标题全是一级）+ `####`787（数字编号列表），层级扁平化，章从关系丢失。

### 2.3 问题③：页眉未去干净

- **全书（双栏页）**：双栏 reflow 路径**完全不执行页眉/页脚/页码移除**（`PdfRouter._dispatch_tier_a` 对 two_col_text 只调 `reflow_page_markdown`，无 `remove_header_footer`）→ 页眉泄漏 142 处（“4 一、招标投标”“12一、招标投标”等），其中部分因字号被误标为标题 `### 12一、招标投标` 进入 chapter 路径；独立页码残留 182 处；书名页眉 2 处。
- **白如银 / 1200问（单栏页）**：页眉泄漏 0 处——但代价是误删正文首行（见 2.6），属“错杀而非漏杀”。

### 2.5 问题⑤：表格未处理 / 表格数据丢失

- **三本书 assembled.md 的 `|` 表格行均为 0，表格占位标签均为 0**——即 3 本书的向量化内容中**没有任何一张表**。
- 机制：Tier A `fast_text` 只有文本抽取，**无表格抽取**；`adapt_pdf_markdown` 的表格原子块逻辑只认 `|` 行，从未触发；MinerU（Tier C）缓存页（1200问 306 页）同样无 `|` 表格。
- 源 PDF 复核：全书/1200问 矢量网格线表格页为 0（多为无边框/文本式排版），白如银检测到 7 页横线均为目录页装饰线。→ 书籍表格以“文本列对齐”为主，快路径完全没有表格感知，**表格内容以纯文本平铺形式进入正文或直接丢失**。

### 2.6 问题⑥：跨页丢字（两个独立机制，均已复现）

**机制一：`remove_header_footer` 顶部 12% 区域误删正文首行**（单栏页）
- 白如银正文首行 y≈76pt，页高 792pt，`top_ratio=0.12` → 阈值 95pt → **正文首行在“页眉区”内被误删**。
- 量化：**白如银 657/661 单栏页（99.4%）、1200问 305/308（99.0%）、全书 1/2** 受影响。
- 复现（直接跑当前 fast_text）：白如银 PDF 第17页首行“试行招标投标，自此招标活动从建设工程开始试点，逐步推广到了机”整行消失；第18页首行“投标人参加投标，招标人按照规定程序评审，并从中择优选择交易对”整行消失。→ 连续正文每页丢一行，句意断裂。

**机制二：`TextCleaner` 删除 <10 字符短行**（双栏页行尾碎片）
- 全书 jsonl 第 12 条 chunk：`…为招标人指定招标代` 后直接接 `招标人具有编制…`，中间的“**理机构。**”（4字）整行被删。
- 双栏 reflow 产生的行尾短碎片（1~9 字）全部被清洗丢弃。

## 3. 通用问题（两条路径）

### 3.1 切片边界崩溃：`<!-- page: N -->` 被当正文

仅 Path A（handoff）存在页标记（Path B 的 cleaned_v1 无页标记）。

| 书 | 含页标记 chunk | 其中页标记从中间截断正文 | 纯页标记空块 |
|---|---|---|---|
| 全书 | 404 / 3913（10.3%） | 310 | 5 |
| 白如银 | **470 / 850（55.3%）** | 395 | 14 |
| 1200问 | 310 / 1179（26.3%） | 209 | 20 |

- 用户案例复现：全书“第十一条 【适用邀请招标的情形】…**经国务院发展计划部门或者省、自治区、直辖市人民政府** ‖ `<!-- page: 16 -->` ‖ **批准，可以进行邀请招标**”同块被页标记从中间切开。
- 根因：页标记是装配层写入的普通行，`TextCleaner` 不滤、`SemanticChunker` 不认（非 `#` 行），全部当正文进 chunk 内容。
- 后果：① 正文被插入 `<!-- page: N -->` 噪声（污染向量）；② 39 个纯页标记空块（全书 5 + 白如银 14 + 1200问 20）产生无意义 embedding；③ 页边界内容跨块断裂。

### 3.2 页眉被误认成标题/正文（Path A）

- 全书 142 处页眉行泄漏，其中 `### 12一、招标投标`（第24页页眉）被 fast_text 字号启发式判为三级标题 → 进入 chapter 路径，如 `目录 > 第五章 法律责任 > 12一、招标投标 > 第三十三条`（93 个 chunk 的 chapter 含页眉/页码噪声）。

### 3.3 标题误判导致切块丢失 / 孤立块

**Path A（全书）**：302 个“第X条【…】+ 正文首句”被拼进标题。典型案例：
```
#### 第十二条【自行办理招标和招标代理】招标人有权   ← 标题（正文首句“招标人有权”被吞）
自行选择招标代理机构，委托其办理招标事宜。任…
```
分块后 chapter=`目录 > 第十二条【自行办理招标和招标代理】招标人有权`，而正文首句“招标人有权”**从块内容中消失**。

**Path B（cleaned_v1）**：法规正文中的“第X条”**引用**被误切成新标题（457 处 / 99 个文件 / 28.4%）：
```
## 第七条 （采购人） 采购人应当按照《政府采购法实施条例》
## 第十一条 第一款的规定，建立健全政府采购内部管理制度，…
```
→ 第七条正文被“第十一条 第一款”引用切成两半，半句标题 + 半句正文各自成孤立块。

## 8. 优化建议方向（本次未改动代码，仅给方向）

1. **页标记**：装配层将 `<!-- page: N -->` 写入独立 metadata（`page_start`/`page_end`），chunk 内容剥离页标记；或 cleaner 直接删除该行并记录边界。
2. **跨页丢字**：`remove_header_footer` 由“固定顶部比例”改为“页眉白名单 + 行首 x 与正文基线对齐”判定；或先 `get_text("dict")` 判断顶部行是否真页眉（与全页文本流拼接验证）。
3. **双栏**：reflow 增加“跨栏句子拼接”后处理（把左栏行尾与右栏行首按语义接续），禁止在 <10 字碎片上切块。
4. **标题**：`_split_heading_inline_articles` 扩展正则以命中 `第X条【…】`、`第X条（…）`；cleaned_v1 入库前先校正“引用误读”标题（“第X条 第X款/规定…”非标题）。
5. **表格**：Tier A 增加表格式文本块检测（多行对齐列），或对疑似表格页升级 Tier C 并启用 MinerU 表格模型；表格块保留 `content_type=table`。
6. **乱码**：新增 LaTeX 语法清洗（`$…$`、`\textcircled`→数字、`\%`）；PyMuPDF 抽取 `??` 时按字体编码回退。
7. **cleaned_v1 元信息**：入库前剥离 `> 发布/来源` 首行；`####` 列表项降级为正文列表。
