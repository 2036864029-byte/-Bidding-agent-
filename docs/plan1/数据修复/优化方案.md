  ### 二、P0：三级路由管线与 Gate 1 前置门禁（最优先）

  #### 2.1 Gate 1 路由判定逻辑（关键，避免误路由）

  Gate 1 必须**精准识别扫描件**，否则电子版被错送 Tier 2 会造成大量算力浪费。

  **判定流程（单页级）：**

  Python

  

  ```python
  def gate1_route(page):
      # Step 1: Tier 1 试探提取
      text_dict = page.get_text("dict")
      raw_text = "".join(block["text"] for block in text_dict["blocks"])
      
      # 指标计算
      metrics = {
          "text_len": len(raw_text.strip()),
          "gibberish_ratio": count_gibberish(raw_text) / max(len(raw_text), 1),
          "img_coverage": calc_image_coverage(page),  # 图片面积 / 页面面积
          "has_embedded_font": check_embedded_fonts(page),
          "table_grid_detected": detect_table_gridlines(page),  # 矢量线检测
          "table_pipe_extracted": "|" in raw_text,  # Tier 1 是否抽出表格结构
      }
      
      # 路由决策
      if (metrics["text_len"] > 50 
          and metrics["gibberish_ratio"] < 0.03 
          and metrics["img_coverage"] < 0.3
          and metrics["has_embedded_font"]):
          # 高质量电子版 → Tier 1
          return "tier_1"
      
      elif (metrics["img_coverage"] >= 0.3 
            or metrics["gibberish_ratio"] >= 0.03 
            or metrics["text_len"] == 0
            or (metrics["table_grid_detected"] and not metrics["table_pipe_extracted"])):
          # 扫描件 / 乱码 / 无文本层 / 有表格框线但 Tier 1 抽不出 → Tier 2
          return "tier_2"
      
      else:
          # 保守降级
          return "tier_2"
  
  # Tier 2 输出后二次质检，不达标则触发 Tier 3
  def gate1_tier2_fallback(tier2_result):
      if tier2_result["gibberish_ratio"] > 0.03 or tier2_result["structure_confidence"] < 0.5:
          return "tier_3"
      return "tier_2"
  ```

  **关键改进**：用 **`img_coverage ≥ 30%`** 和 **`gibberish_ratio ≥ 3%`** 作为扫描件/低质量页的核心指标，而非简单依赖「有无文本层」。这能避免纯图片扫描件漏检，也能防止正常电子版因字体缺失被误判。

  #### 2.2 Tier 1 (PyMuPDF) 核心 Bug 修复

  评估报告显示，Tier 1 当前处理了 80%+ 的页面，但存在系统性丢字。**这些修复对电子版书籍（全书/白如银/1200问）至关重要**。

  表格

  

  

  | 修复点                   | 原代码问题                                                   | 修复方案                                                     | 预期效果                                                 |
  | :----------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :------------------------------------------------------- |
  | **remove_header_footer** | 固定 `top_ratio=0.12`（95pt），单栏正文首行 y≈76pt 被误删；双栏路径完全不调用 | 1. 改为**动态模式识别**：统计全页重复行（出现≥3次且非正文句），标记为页眉/页脚。 2. 双栏 `reflow_two_columns` 路径**补充调用** `remove_header_footer`。 3. 保留 `y ≥ 70pt` 区域作为「正文保护区」，仅当该行匹配重复模式时才删除。 | 白如银/1200问 99%+ 首行误删清零；全书 142 处页眉泄漏清零 |
  | **reflow_two_columns**   | 只重建阅读顺序，不做行合并；标题被从中间截断                 | 1. **跨栏句子拼接**：左栏行尾无句末标点（。；！？）且右栏行首非标点时，合并两行。 2. **标题跨栏保护**：若行以 `第X条` / `第X章` 开头但在页边截断，强制与下一行拼接后再做标题判定。 | 双栏碎片丢失清零；标题截断减少                           |
  | **TextCleaner**          | 硬删 `<10` 字短行，双栏行尾碎片（「理机构。」4字）被丢弃     | 1. **取消字数硬删规则**。 2. 改为**句末标点缝合**：遍历行序列，若上行无终止标点且下行首字非标点，则拼接为一句。 | 双栏碎片不再丢失；跨页句子连续性恢复                     |

  #### 2.3 Tier 2 (PaddleOCR/PP-Structure) 设计与后处理

  **定位**：扫描件主力 + 标准表格提取 + Tier 1 质量不达标页的降级处理。

  **执行流程：**

  Python

  

  ```python
  def tier2_process(page_image):
      # 1. PP-Structure 版面分析
      result = pp_structure(page_image)
      
      # 2. 区域分类处理
      elements = []
      for region in result["regions"]:
          if region["type"] == "header":
              continue  # 直接丢弃页眉
          elif region["type"] == "footer":
              continue  # 直接丢弃页脚
          elif region["type"] == "table":
              # 表格结构化保留
              md_table = convert_to_markdown_table(region["html"])
              elements.append({
                  "type": "table",
                  "content": md_table,
                  "content_type": "table"
              })
          elif region["type"] in ["title", "text"]:
              elements.append({
                  "type": region["type"],
                  "content": region["text"],
                  "bbox": region["bbox"]
              })
      
      # 3. 标题层级映射（PP-Structure 标题 → 统一规范）
      markdown_lines = []
      for elem in elements:
          if elem["type"] == "title":
              level = map_title_level(elem["content"])  # 第X章→#, 第X节→##, 第X条→###
              markdown_lines.append(f"{'#' * level} {elem['content']}")
          else:
              markdown_lines.append(elem["content"])
      
      return "\n\n".join(markdown_lines)
  ```

  **PP-Structure 标题映射规则：**

  表格

  

  

  | PP-Structure 识别类型 | 内容模式                      | 映射为        |
  | :-------------------- | :---------------------------- | :------------ |
  | title                 | `第[一二三...]章`             | `#`           |
  | title                 | `第[一二三...]节` / `第\d+节` | `##`          |
  | title                 | `第[一二三...]条` / `第\d+条` | `###`         |
  | title                 | `（一）` / `1.` / `一、`      | 正文列表 `- ` |
  | text                  | 正文                          | 正文          |

  **关键改进**：PP-Structure 能直接输出 `header`/`footer`/`table` 区域类型，**天然解决页眉泄漏和表格丢失问题**。扫描件书籍的表格应在此层被完整提取。

  #### 2.4 Tier 3 (MinerU) 兜底与输出对齐

  **触发条件**：

  - Tier 2 解析失败（如 PP-Structure 返回空结果）
  - Tier 2 输出乱码率仍 > 3%
  - 页面被标记为「极度混乱版面」（如密集嵌套表格、严重歪斜）

  **输出后处理（必须做，否则 MinerU 页与 Tier 1/2 混排会层级倒挂）：**

  Python

  

  ```python
  def tier3_post_process(mineru_md):
      # 1. 标题降级：MinerU 习惯全用 #，需按字号/上下文重新映射
      lines = mineru_md.split("\n")
      new_lines = []
      for line in lines:
          if line.startswith("# ") and is_likely_section(line):  # 第X节
              new_lines.append(line.replace("# ", "## "))
          elif line.startswith("# ") and is_likely_article(line):  # 第X条
              new_lines.append(line.replace("# ", "### "))
          else:
              new_lines.append(line)
      return "\n".join(new_lines)
  ```

  ### 三、P1：页标记隔离与通用清洗（所有 Tier 统一出口）

  无论哪一 Tier 处理，输出后必须经过统一清洗管线，确保格式一致。

  #### 3.1 页标记彻底剥离

  **当前问题**：`<!-- page: N -->` 作为普通文本行写入，污染 10%~55% 的 chunk。

  **修复**：

  Python

  

  ```python
  # pdf_markdown_assembler.py —— 装配层不再写入页标记行
  def assemble_pages(pages):
      chunks = []
      current_chunk = {"content": [], "page_start": None, "page_end": None}
      
      for i, page in enumerate(pages):
          if current_chunk["page_start"] is None:
              current_chunk["page_start"] = page.page_num
          
          current_chunk["content"].append(page.markdown)
          current_chunk["page_end"] = page.page_num
          
          # 按语义大小切分 chunk，页标记绝不进入 content
          if should_split(current_chunk):
              chunks.append(current_chunk)
              current_chunk = {"content": [], "page_start": None, "page_end": None}
      
      return chunks
  ```

  **效果**：页标记从正文消失，转为 chunk metadata 的 `page_start`/`page_end`；向量库检索不再被 `<!-- page: 16 -->` 噪声干扰。

  #### 3.2 LaTeX 与符号清洗（cleaner.py）

  表格

  

  

  | 乱码类型                            | 清洗规则                                            | 示例                       |
  | :---------------------------------- | :-------------------------------------------------- | :------------------------- |
  | `$...$` 伪数学                      | 提取内部纯文本；若含 `@` / `.com` 则保留为邮箱/网址 | `$@$` → `@`                |
  | `\textcircled{N}`                   | 归一化为 `(N)`                                      | `\textcircled{1}` → `(1)`  |
  | `\boldsymbol{...}` / `\mathit{...}` | 剥离标签，保留内容                                  | `\boldsymbol{ABC}` → `ABC` |
  | `??`（百分比丢失）                  | 上下文推断为 `%`；无法推断则标记 `[?]`              | `2??` → `2%`               |
  | U+00A0 非断行空格                   | 替换为普通空格                                      | `\xa0` → ` `               |
  | 图片链接 `![](images/*.jpg)`        | 本地文件不存在则替换为 `[图片]` 或删除              | 避免死链入库               |

  #### 3.3 条标题内联正文拆分（扩展正则）

  评估报告显示 302 处（Path A）+ 7188 处（Path B）条标题吞并正文。

  Python

  

  ```python
  # _split_heading_inline_articles 扩展
  SPLIT_PATTERNS = [
      # 模式1: 第X条【标题】正文
      r'(第[一二三四五六七八九十百千\d]+条【[^】]+】)([^\n])',
      # 模式2: 第X条（标题）正文  
      r'(第[一二三四五六七八九十百千\d]+条（[^）]+）)([^\n])',
      # 模式3: 第X条 正文（原逻辑已支持，保留）
      r'(第[一二三四五六七八九十百千\d]+条)\s+([^\n])',
  ]
  
  def split_heading_inline_articles(text):
      for pattern in SPLIT_PATTERNS:
          text = re.sub(pattern, r'\1\n\n\2', text)
      return text
  ```

  ### 四、P2：Gate 2 后置校验与规范化闭环

  Gate 2 的定位是**兜底校验**，而非主要修复手段。规则应精简、可量化。

  #### 4.1 校验规则

  表格

  

  

  | 校验项             | 规则                                                         | 未通过时的自动修复                               |
  | :----------------- | :----------------------------------------------------------- | :----------------------------------------------- |
  | **标题层级**       | `第X章` 必须为 `#`；`第X条` 必须为 `###`；`（一）` 不能为 `####` | 自动调整 `#` 数量；`#### （一）` → `- （一）`    |
  | **条标题内联正文** | `### 第X条【...】` 后必须紧跟换行                            | 强制插入 `\n\n`                                  |
  | **法条引用误判**   | 若 `## 第X条` 后紧跟「第Y款/的规定/参照…」且行长度 > 30 字   | 降级为正文，剥离 `#`                             |
  | **目录页污染**     | 检测到 `## 目 录` 后，其下内容若为 `….页码` 模式             | 隔离为 `content_type=toc`，禁止进入 chapter 路径 |
  | **空块/纯标记块**  | chunk 内容仅含 `<!-- page: N -->` 或 `< 15` 字               | 丢弃该 chunk                                     |
