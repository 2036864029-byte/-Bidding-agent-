   - 移动或重命名文件/目录时，同步更新全工程所有涉及的 import 相对与绝对路径。

- 该工具接收文件路径/字节流，返回清洗后的 Markdown 文本，用于用户临时上传文件的单次问答。

9.批量解析文件夹路径：**“默认目录 + 参数覆盖”** 是标准做法：

- **不要写死在代码逻辑里**，而是写进 `core/config/settings.py` 配置文件中（如设置 `DATA_RAW_DIR = "./data/docs_input"`）。
- CLI 或 API 允许传入自定义路径。如果不传，就自动去默认的 `docs_input` 路径下读取文件。
