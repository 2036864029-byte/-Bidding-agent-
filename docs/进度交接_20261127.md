## 6. 今天新踩的坑（补进踩坑清单）

| 坑 | 现象 | 结论 |
|---|---|---|
| **compose 的 `ports` 是「追加」不是「替换」** | 叠加文件里再写一条 `127.0.0.1:8000:8000`，容器启动报 `failed to bind host port: address already in use` | 回环绑定下沉到基础文件（`${API_BIND_ADDR:-127.0.0.1}`），叠加层**不要**碰 `ports` |
| **PowerShell 管道传密码会多一个换行** | `$pw \| docker login --password-stdin` → `denied: Authenticate Error`，其实密钥是对的 | Windows 上用 `-p`；CI 里用 bash 的 `echo -n` |
| **SWR 页面上传有 2 GB 上限（含解压后）** | 2.74 GB 镜像被拒 | 用 `docker push`（无此限制）；顺手把镜像瘦到 1.5 GB |
| **uv 的下载缓存会打进镜像** | `/root/.cache` 占 **891 MB**，镜像 2.74 GB | Dockerfile 加 `UV_NO_CACHE=1` + `rm -rf /root/.cache` → 1.5 GB |
| **服务器 Docker Hub 不通** | `dial tcp 31.13.71.19:443: i/o timeout` | `/etc/docker/daemon.json` 配 registry-mirrors（已配好） |
| **浅克隆后 `git pull` 会卡** | `git clone --depth 1` 再 `pull` 超时 | 用 `git fetch --depth 1 && git reset --hard origin/main`；或直接 SFTP 覆盖文件 |
